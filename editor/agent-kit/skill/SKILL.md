# NovelTea Project

1. Run `noveltea agent sync` from the project or pass `--project <root>`.
2. Read `.noveltea/agent/GUIDE.md`.
3. Follow the generated project-format and focused authoring guidance.
4. Edit ordinary project source directly, then run `noveltea validate`.
5. Use NovelTea semantic CLI commands for create, rename, delete, usages, native tooling, tests, and package export.
