# NovelTea Agent Guide

This directory is generated by the installed NovelTea CLI. Run `noveltea agent sync` at the start of each agent session before relying on these files.

NovelTea projects are file-first workspaces. Read and edit tracked JSON, Lua, RML, and RCSS directly for ordinary authoring changes, then run `noveltea validate`. Use the CLI for semantic operations that need whole-project knowledge or transactions: create, rename, delete, usages, shader compilation, tests, and package export.

Never edit `.noveltea/` as project source. It contains disposable or tool-owned editor, transaction, cache, build, trash, and generated agent state. Follow the root `AGENTS.md` and do not edit its marked NovelTea-managed block.

Read `PROJECT_FORMAT.md` before changing project files, `CLI.md` before structural operations, and the focused documents under `docs/` for authoring semantics. Machine-readable workspace-v1 schemas are under `schemas/`.

When the editor is open, continue editing tracked project source normally. If the editor reports a conflict, resolve it through the editor or the tracked source involved; never modify `.noveltea/` to bypass it.
