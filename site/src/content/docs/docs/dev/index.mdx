NovelTea is a narrative-game engine and editor built around portable project data, a native runtime, Lua scripting, and export targets including desktop and Web.

## What belongs here

The public documentation focuses on authors using NovelTea rather than the engine's internal implementation. As the development surface stabilizes, this section will grow to cover project structure, rooms and interactions, UI authoring, scripting, validation, preview, and export workflows.

## Current status

NovelTea has not published its first public release yet. For now, `/docs/dev` is the canonical public documentation channel and tracks current development rather than a compatibility promise.
