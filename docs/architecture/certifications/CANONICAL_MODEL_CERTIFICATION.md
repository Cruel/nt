# Canonical Model End-to-End Certification

Certification date: 2026-08-26.

This record closes issue #102 by certifying the current pre-release canonical authoring,
compiled-project, runtime, presentation, editor-playback, save/restore, and platform seams. It does
not create or advance a compatibility version. All already-selected compatibility boundaries remain
at their existing versions; current-only authoring and nested schemas remain version-neutral.

## Canonical executable projects

The checked-in cross-language golden corpus contains four certification fixtures generated by the
real authoring compiler:

- `canonical-linear.json` is a Room-free Scene entrypoint that calls Dialogue, reaches a save-safe
  Dialogue checkpoint, restores through `RunningGame::prepare_load_candidate()` /
  `commit_candidate()`, resumes the same Dialogue, and completes the game. Native certification
  passes 28 assertions.
- `canonical-exploration.json` starts in an ordinary Room and publishes Room, Map, Inventory, Feature,
  and Interaction state. Stable Feature and Interactable subjects drive the normal subject-first
  Interaction path; the invoked Scene creates runtime Room/Interactable identities, creates an Item
  Stack quantity, mutates gameplay state, and mounts a stateful Layout. The test commits session
  Layout state, saves, restores atomically with the same runtime-created identities and Item Stack,
  then navigates away and back to prove Room lifecycle execution and fresh Lua `on_ready` ordering.
  Native certification passes 59 assertions.
- `canonical-flow.json` drives one Dialogue through two Handoffs. The first handoff invokes a
  staged-Room flashback, then resumes the exact suspended Dialogue at its second line; the second
  handoff crosses an ordinary parent-Scene interlude and resumes the exact same Dialogue frame at its
  third line. Public presentation state proves the staged Room's presentation exists only during the
  child invocation and is removed on return. Native certification passes 82 assertions.
- `canonical-vocabulary.json` is deliberately exhaustive rather than a gameplay walkthrough. It
  contains every current Scene instruction/stage/terminal family, Dialogue segment and cue family,
  Subject Selector family, Interaction instruction family, gameplay mutation family, runtime-world
  operation/configuration-source family, material target, TransitionGroup child, Archetype kind, and
  the current Item Stack vocabulary. TypeScript asserts the closed sets explicitly and the native
  decoder consumes the generated bytes.

The golden generator is the only producer for these files. They are not hand-maintained native test
fixtures, so compiler and decoder disagreement fails the same cross-language seam used by export.

## Stable semantic playback contract

Authoring Tests and Play-preview recording use semantic runtime identities only:

- Dialogue choices record exact Dialogue Edge IDs.
- Scene choices record exact Scene Choice Option IDs.
- Room navigation records exact Room Exit IDs.
- Interaction subjects preserve Character, Interactable, exact Item Stack, and owner-qualified
  Feature identity.
- Test-local entrypoints, arbitrary init/check Lua, starting-inventory mutation, index-based choices,
  direction-based navigation, UI-click selectors/coordinates, arbitrary load payloads, and the old
  Test assertion DSL are not current schema members.

The native editor playback protocol strictly rejects the retired index/direction forms. Playback
reports expose handled state, diagnostics, runtime events, and coherent public publications instead
of a second assertion/evaluation language. The dedicated RuntimeUI playback driver remains separate
for UI implementation tests and does not become an authoring Test input surface.

## Strict current wire contract

The current Compiled Project decoder remains a single strict reader. Certification explicitly covers
the complete generated vocabulary and rejects a superseded same-version Scene shape. Existing native
strictness suites additionally reject unknown fields, unknown variants, unsupported old/provisional
schema forms, malformed references, and incompatible specialized fields. No alias reader, dual
writer, alternate current shape, or legacy runtime controller was added.

Certification exposed and fixed one real producer defect: Room Archetype lowering emitted a
`lifecycle.hooks` member that is not part of the canonical compiled Room lifecycle shape. The authoring
compiler now emits only the strict current Room Archetype lifecycle contract; script hooks remain in
their canonical separate field.

## Result

The canonical VN-first model is exercised through the real authoring compiler, strict compiled wire,
final native loader, `RunningGame`, save/load candidate replacement, public runtime publications,
preview/playback protocol, Linux/Web players, and Android native packaging. Certification depends on
stable semantic identities and public runtime observations, not UI positions, gesture coordinates,
list indexes, alternate writers, or legacy compatibility paths.
