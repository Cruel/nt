# Synthetic UI samples

Project-authored PNGs for Feature Lab, no third-party source. `ui-pattern.png` is a 192×128 RGBA two-color grid with a transparent central hole and one-pixel white rules. `cursor-marked.png` is an asymmetric 32×48 L with a magenta marker centered at source hotspot (4,5). `cursor-oversized.png` repeats the exact pixels at 8× scale (256×384), with corresponding hotspot (32,40), to exercise portable 128-pixel fitting. Nearest sampling is intentional; these are functional fixtures, not curated artwork.
